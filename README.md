# Django Docker Project

Проект представляет собой Django-приложение, упакованное в Docker-контейнеры вместе со всеми необходимыми сервисами (База данных, Redis, Celery).

## 1. Настройка переменных окружения

Скопируйте файл `.env.example` в `.env` и заполните его данными (пароли, ключи):

```bash
cp .env.example .env
```
## 2. Запуск проекта

docker-compose up --build
